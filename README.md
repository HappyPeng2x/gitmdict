# gitmdict

Git-friendly JSON representation of [JMdict](https://www.edrdg.org/jmdict/j_jmdict.html), generated by
[SumatoraIndex](https://github.com/HappyPeng2x/SumatoraIndex)'s `jmdict-to-git.py`. This is stage 1 of the
Sumatora dictionary pipeline: one JSON file per entry (`entries/<shard>/<seq>.json`) and one per
entry/language translation (`translations/<lang>/<shard>/<seq>.json>`), sharded by `seq // 10000`.

This repository is regenerated and pushed automatically by SumatoraIndex's monthly release workflow, so
it always reflects the current upstream JMdict snapshot plus any local patches
(see `patches/` in SumatoraIndex). Manual edits here will be overwritten on the next sync.
